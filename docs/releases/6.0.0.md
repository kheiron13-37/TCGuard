# TCGuard 6.0.0

*11 Kasım 2026 / 11 November 2026* · Gate 1.2.0 değişmedi / Gate 1.2.0 is unchanged

## Türkçe

### 1.8'den 1.21'e tek jar
5.x yalnız 1.8'de çalışıyordu. 6.0.0 aynı jar ile 1.8 - 1.21 arasındaki Spigot ve Paper
sunucularda çalışır. Gerçek sunucuda denenen sürümler: 1.8.8, 1.12.2, 1.16.5, 1.20.4, 1.21.8.

| Koruma | 1.8 | 1.9 - 1.21 |
| --- | --- | --- |
| Aşırı büyük paket, sıkıştırma bombası | var | var |
| Paket seli | var | var |
| Log4Shell, exploit komutları, op listesi | var | var |
| PROXY protocol ve origin kilidi (Gate) | var | var |
| Paket içeriği (NBT, kitap, tabela, tıklama), eşya düzeltme, end portal yamaları | var | yok |

Son satır 1.8 paket biçimine ve 1.8 davranışına bağlıdır. Yeni sürümlerde paket biçimi neredeyse
her güncellemede değişir ve sunucunun kendi sınırları vardır; orada tekrarlanmadı.

### ProtocolLib gerekmiyor
Eklenti artık tek başına çalışır. ProtocolLib'in yaptığı iş (çözülmüş paketleri dinlemek) kalktı;
gereken kontroller paket çözülmeden önce çalışan denetleyiciye taşındı.

### Kaldırılan kontroller
Her biri TCGuard'sız bir 1.8.8 sunucuda denendi ve sunucunun zaten hallettiği görüldü. İşe
yaramayan kod durmasın diye silindi:

- NaN konum, geçersiz hotbar slotu: sunucu kendisi atıyor.
- Survival'da creative paketi, elde kitap yokken kitap düzenleme: sunucu yok sayıyor.
- Dünya dışına ateşleyen dispenser, makassız kırkma, kapak üstüne redstone, bow bomb, yüklenmemiş
  chunk'a hareket, dünyalar arası açık kalan sandık.

Kalan dünya yaması yalnız end portalını korur (kova, dispenser, mantar); bunlar korumasız sunucuda
gerçekten portalı siliyor.

### Yeni kontroller (1.8)
- Araç girdisinde NaN / sonsuz değer.
- Tabelada ve yazılı kitapta translate bileşeni (sunucunun ana iş parçacığında katlanarak açılır).
- Geçersiz slot, tuş ya da modla pencere tıklaması artık paket çözülmeden reddediliyor.

### Düzeltmeler
- Log filtresi güncel sunucularda yanlış logger bağlamına takılıyor ve hiçbir şey süzmüyordu.
  Artık sunucunun log yapılandırmasına doğrudan takılıyor.
- Sohbette ya da komutta Log4Shell araması her sürümde reddedilir; loga da diğer oyuncuların
  istemcisine de gitmez.
- Sınırı aşan sıkıştırılmamış paket, açıcıya ya da ViaVersion gibi çeviricilere ulaşmadan reddedilir.
- Bir ihlal seviyesinin eylemleri oyuncu başına beş saniyede en fazla bir kez çalışır. Puanı bir
  seviyenin etrafında gidip gelen istemci her geçişte yeni uyarı üretiyordu.
- Atılan oyuncunun bağlantısında kuyrukta kalan paketler yeni bir kayda puan yazıyor, atılma
  uyarıları ikinci kez çıkıyordu. Artık bu paketler düşürülüyor.

### Yükseltme
1. Eski jar'ı silip `TCGuard-6.0.0.jar` dosyasını koyun.
2. Başka eklenti kullanmıyorsa ProtocolLib'i kaldırabilirsiniz.
3. Config aynı kalır. Tek yeni ayar `frames.modern-max-bytes` (yalnız 1.9+ için, varsayılan 1 MB).
4. Gate 1.2.0 ile uyumludur; gate dosyasını değiştirmeniz gerekmez.

### Test edilmeyenler
Aradaki sürümler (1.9 - 1.11, 1.13 - 1.15, 1.17 - 1.19 ...), Folia, modlu istemciler, BungeeCord /
Velocity arkasındaki kurulumlar, Windows'ta Gate. Ayrıntı: [docs/TESTING.md](../TESTING.md).

## English

### One jar from 1.8 to 1.21
5.x ran on 1.8 only. 6.0.0 runs on Spigot and Paper from 1.8 to 1.21 with the same jar. Versions
exercised on a real server: 1.8.8, 1.12.2, 1.16.5, 1.20.4, 1.21.8.

| Protection | 1.8 | 1.9 - 1.21 |
| --- | --- | --- |
| Oversized frames, compression bombs | yes | yes |
| Packet floods | yes | yes |
| Log4Shell, exploit commands, operator list | yes | yes |
| PROXY protocol and origin lock (Gate) | yes | yes |
| Packet contents (NBT, books, signs, clicks), item correction, end portal patches | yes | no |

The last row depends on the 1.8 packet format and 1.8 behaviour. Newer versions change the format
with almost every release and have limits of their own; the checks are not repeated there.

### ProtocolLib is not needed
The plugin stands alone. The part ProtocolLib served (listening to decoded packets) is gone; the
checks that mattered moved into the guard that runs before packets are decoded.

### Removed checks
Each was tried against a 1.8.8 server without TCGuard and turned out to be handled by the server
already. They were deleted so that no code is there for show:

- NaN position, invalid hotbar slot: the server kicks by itself.
- Creative packet in survival, book edit without a book in hand: the server ignores them.
- Dispenser firing out of the world, shearing without shears, redstone on a trapdoor, bow bomb,
  movement into unloaded chunks, containers left open across worlds.

The remaining world patch protects end portals only (bucket, dispenser, mushroom); on an
unprotected server those do remove the portal.

### New checks (1.8)
- NaN or infinite vehicle input.
- Translate components on signs and in written books (they expand exponentially on the server's
  main thread).
- Window clicks with an invalid slot, button or mode are now refused before decoding.

### Fixes
- On current servers the log filter attached itself to the wrong logger context and filtered
  nothing. It now attaches to the server's logging configuration directly.
- A Log4Shell lookup in chat or a command is refused on every version; it reaches neither the log
  nor other players' clients.
- An uncompressed frame above the size limit is refused before it reaches the decompressor or a
  translator such as ViaVersion.
- A violation level's actions run at most once in five seconds per player. A client whose score
  hovered around a level used to trigger a new alert on every crossing.
- Frames still queued on a connection after its player was kicked were scored against a fresh
  record, which repeated the kick's alerts. They are dropped now.

### Upgrading
1. Replace the old jar with `TCGuard-6.0.0.jar`.
2. Remove ProtocolLib if no other plugin uses it.
3. The config stays as it is. The one new option is `frames.modern-max-bytes` (1.9+ only, default 1 MB).
4. Works with Gate 1.2.0; the gate binary does not need replacing.

### Not tested
The versions in between (1.9 - 1.11, 1.13 - 1.15, 1.17 - 1.19 ...), Folia, modded clients, setups
behind BungeeCord / Velocity, the Gate on Windows. Details: [docs/TESTING.md](../TESTING.md).
