# TCGuard 5.2.0 + TCGuard Gate 1.2.0

*11 Kasım 2026 / 11 November 2026*

## Türkçe

### Origin kilidi
Sunucunun IP adresini gizlemek yetmez; adres eski DNS kayıtlarından, dışarıya bağlanan eklentilerden
ya da hosting aralığının taranmasından sızabilir. Origin kilidiyle adresin bilinmesi önemini
kaybeder, çünkü sunucu yalnız gate ile konuşur.

- `gate.json` içine `"secret"`, eklenti config'ine aynı değerle `proxy-protocol.secret` yazılır.
- Gate ilettiği her bağlantıyı imzalar: zaman damgası ve oyuncu adresi üzerinde HMAC-SHA256.
- Eklenti imzayı sunucu tek bayt okumadan önce doğrular. İmzasız, yanlış anahtarla imzalı,
  30 saniyeden eski ya da daha önce kullanılmış imza taşıyan bağlantı kapatılır.
- Kilit adrese bağlı olmadığı için gate başka makinelerde çalışabilir. Birkaç küçük sunucuya gate
  kurup DNS'e onların adresini yazarsanız oyuncular yalnız gate'leri görür.

### Bunun yerini tutmadığı şey
Hacimli DDoS (onlarca-yüzlerce Gbit/s ham trafik) hedefin hattını, herhangi bir program paketi
görmeden doldurur. Bunu emmek altyapı işidir. Böyle saldırı bekliyorsanız gate'leri DDoS filtresi
olan bir hosting'e ya da bir filtre servisinin arkasına koyun; asıl sunucu arkada gizli kalsın.

### Ayrıca (Gate 1.1.0)
- Tek gate birden çok sunucunun önünde durabilir (`routes`).
- BungeeCord, Waterfall, FlameCord, Aegis ve Velocity ile PROXY protocol uyumluluğu belgelendi.
- Dünya yamalarının canlı testleri eklendi (W02-W06).

### Yükseltme
Jar'ı ve gate dosyasını değiştirin. Config biçimi 5.1.0 ile aynı; `secret` boşken davranış değişmez.
Saatler NTP ile eşitlenmiş olmalı.

## English

### Origin lock
Hiding a server's address is not enough; it leaks through old DNS records, plugins that call home,
or a scan of the hosting range. With the origin lock it stops mattering who knows the address,
because the server only talks to the gate.

- Put `"secret"` in `gate.json` and the same value in `proxy-protocol.secret` in the plugin config.
- The gate signs every connection it forwards: a timestamp and an HMAC-SHA256 over the player's
  address.
- The plugin verifies the signature before the server reads a single byte. Unsigned, wrongly
  signed, older than 30 seconds, or already used: the connection is closed.
- The lock does not depend on addresses, so gates can run on other machines. Put gates on a few
  small servers, publish their addresses in DNS, and players only ever see the gates.

### What it does not replace
A volumetric DDoS (tens to hundreds of Gbit/s of raw traffic) fills the target's link before any
program sees a packet. Absorbing that is infrastructure. If you expect it, run the gates at a host
with DDoS filtering or behind a filtering service, and keep the real server hidden behind them.

### Also (Gate 1.1.0)
- One gate can front several servers (`routes`).
- PROXY protocol compatibility with BungeeCord, Waterfall, FlameCord, Aegis and Velocity is documented.
- Live tests for the world patches (W02-W06).

### Upgrading
Replace the jar and the gate binary. The config format is the same as 5.1.0; with `secret` empty
nothing changes. Clocks must be synchronised (NTP).
