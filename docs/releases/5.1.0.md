# TCGuard 5.1.0 + TCGuard Gate 1.0.0

*11 Kasım 2026 / 11 November 2026*

## Türkçe

### TCGuard Gate (yeni)
Sunucunun ya da BungeeCord/Velocity'nin önüne konan küçük bir program. Eklentinin göremediği her şeyi,
yani oyuncu giriş yapmadan önceki kısmı karşılar:
- Sunucu listesi ping'leri önbellekten cevaplanır. Testte 600 ping'e karşılık sunucuya 1 istek gitti.
- Handshake'i bitirmeyen soketler 5 saniyede kapanır. Testte 250 sessiz soket kapandı, aynı anda
  oyuncu girebildi.
- Adres başına açık bağlantı ve bağlanma hızı sınırlanır; saniyede gereğinden fazla giriş
  "Server is busy" ile geri çevrilir.
- Bozuk handshake, eski ping, HTTP trafiği ve geçersiz isimler sunucuya hiç ulaşmaz.
- Giriş sonrası yükleme sınırı: sunucunun belleğe aldığı 2 MB'lık yarım çerçeve gate'te kesilir.
  Bu saldırıyı eklenti göremez.
- Oyuncunun gerçek IP'si arkaya PROXY protocol v2 ile gider.

### Eklenti 5.1.0
- `proxy-protocol.trusted`: gate ya da HAProxy arkasında gerçek IP. Güvenilir adresten başlıksız
  gelen bağlantı reddedilir, böylece aynı makinedeki biri gate'i taklit edemez.

### Proje
- Fuzzer: paket denetleyicisi her testte 200.000 rastgele çerçeveyle deneniyor.
- `docs/EXPLOITS.md`: her korumanın hangi testle kanıtlandığı. Testi olmayanlar açıkça yazılı.
- Güvenlik bildirimi süreci (`SECURITY.md`), katkı kuralları, şablonlar ve CI.

### Kurulum
`docs/DEPLOYMENT.md`. En önemli kural: arkadaki sunucu internete kapalı olmalı, yoksa saldırgan
gate'in etrafından dolaşır.

### Doğrulama
Eklenti tek başına 34/34; gate önündeyken eklentinin 34 testi ve gate'in 9 testi birlikte 43/43.
Eklenti birim testleri 48/48, gate birim testleri 10/10. Ayrıntı: [docs/TESTING.md](../TESTING.md).

## English

### TCGuard Gate (new)
A small program in front of the server or of BungeeCord/Velocity. It covers what the plugin cannot
see, everything before the player has logged in:
- Server-list pings are answered from a cache: 600 pings caused 1 backend request in the test.
- Sockets that never finish the handshake are closed after 5 seconds: 250 silent sockets were
  dropped while a player could still join.
- Open connections and connect rate per address are limited; logins above the per-second limit are
  turned away with "Server is busy".
- Malformed handshakes, legacy pings, HTTP traffic and invalid names never reach the server.
- An upload budget after login: a 2 MB partial frame, which the server would buffer in memory, is
  cut at the gate. The plugin cannot see this attack.
- The player's real address goes to the backend as a PROXY protocol v2 header.

### Plugin 5.1.0
- `proxy-protocol.trusted`: real addresses behind the gate or HAProxy. A trusted address that sends
  no header is refused, so nobody on the same machine can pose as the gate.

### Project
- Fuzzer: the frame inspector is run against 200,000 random frames on every test run.
- `docs/EXPLOITS.md`: the test behind every protection, with the untested ones listed as such.
- Security reporting process (`SECURITY.md`), contribution rules, templates and CI.

### Setup
`docs/DEPLOYMENT.md`. The one rule that matters: the backend must not be reachable from the
internet, or attackers go around the gate.

### Verification
Plugin alone 34/34; with the gate in front the 34 plugin checks and 9 gate checks pass together,
43/43. Plugin unit tests 48/48, gate unit tests 10/10. Details: [docs/TESTING.md](../TESTING.md).
